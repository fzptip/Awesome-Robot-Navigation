Add a paper

This site is built from the repository's README, so every change goes through GitHub. Once it is merged, the site updates within a few minutes.

  1. Check it is not listed yetSearch on the Papers page by title or first author.
  2. Suggest it, or edit the READMEOpen an issue with the paper form, or add it to README.md in a pull request.
  3. Write one line in the house formatOfficial version first; link to the DOI or proceedings page when there is one, arXiv otherwise.
  4. List it in every section it belongs toA VLA model for drones belongs under Foundation Model-Based Navigation and Unmanned Aerial Vehicles. Write it identically each time.
  5. Keep the orderNewest year first, then titles A to Z within a year.
